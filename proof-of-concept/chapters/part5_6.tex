\subsection{Quy trình build}

Quy trình build được tự động hóa qua Makefile:

\begin{itemize}[topsep=0pt, itemsep=2.5pt, leftmargin=1.5cm]
    \item \textbf{\texttt{make build}}: Biên dịch TypeScript (\texttt{tsc}) và Less (\texttt{lessc}), output vào thư mục \texttt{build/}.
    \item \textbf{\texttt{make server}}: Chạy server ở chế độ development (Node.js + tsx, watch mode).
    \item \textbf{\texttt{make deploy-server}}: CI/CD — GitHub Actions build Docker image và push lên Hugging Face Spaces.
    \item \textbf{\texttt{make deploy-pages}}: CI/CD — Build frontend và push lên GitHub Pages.
\end{itemize}
